# DiskStats 1.1.0

Package version: 1.1.0.0 (Windows x64).

## Changes

- Added a drive health window with physical disk selection, Windows health
  status, and supported SMART/NVMe metrics. Queries are read-only and do not
  request elevation. Unavailable counters are explicitly marked.
- Added disk speed measurements with a 1 GiB test file: sequential, random
  4 KiB and 64 KiB, and mixed read/write tests, including IOPS and access time.
- Centered the toolbar icons and added the heart/pulse health shortcut.
- Applied the MIT License to DiskStats and included native dependency notices
  in the distribution's `licenses` directory.

## Validation

- Release tests: 1,335 passed (281 Core and 1,054 App), none skipped.
- Health metrics were read successfully from a local NVMe SSD without elevation.
- Light/dark health windows and toolbar icon alignment were checked.
- `packaging/build.ps1 -Store` created the self-contained .NET 10.0.12 MSIX.
- Package identity/version and bundled license hashes were verified.
