# DiskStats 1.2.0

Package version: 1.2.0.0 (Windows x64).

- Select multiple files with Ctrl-click in charts and the file table.
- See the hovered file path in the status bar and a compact selection tree in the sidebar.
- Review selected paths in a confirmation dialog before deleting files.
- Distinguish overview colors more easily with a higher-contrast palette.
- Press Space to preview images, plain text, and video; Escape closes the preview. Video playback uses Windows Media Foundation and installed codecs.
- Move selected files to another folder or drive with a capacity check, confirmation, and Windows progress and conflict handling.
- Explore folder growth over 7, 30, or 90 days, or all retained scans. History requires at least two snapshots and does not schedule scans automatically.
- Save and reuse named filter presets.

## Downloads

The portable Windows x64 ZIP includes the .NET runtime. Extract the complete archive and run DiskStats.App.exe.
The unsigned MSIX is the Microsoft Store submission artifact; use the Store for normal packaged installation.

## Validation

The Release test suite passed 1,431 tests. Native video playback and moving a synthetic file were also checked locally.
