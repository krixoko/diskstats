# README screenshots

Captured from DiskStats 1.1.0 using Avalonia Headless with the Skia renderer.
The screenshots show the real application controls without image compositing.

| File | View |
|---|---|
| `treemap.png` | Treemap, light theme |
| `files.png` | File table, light theme |
| `sunburst.png` | Sunburst, light theme |
| `top-sizes.png` | Largest files, dark theme |
| `disk-speed.png` | Disk speed dialog, illustrative results |
| `drive-health.png` | Drive health dialog, illustrative values |

The main window uses the synthetic `C:\DiskStats-Demo` fixture created for the
Store screenshots: 72 placeholder files, approximately 4.1 GiB. The drive sidebar
uses a demo label and illustrative capacity. The dialogs receive synthetic
benchmark/health data through their existing reader interfaces; their status
lines explicitly identify the values as examples. No disk benchmark or SMART
query was run for these screenshots, and no personal files are shown.
