# DiskStats Store screenshots

Eight PNG screenshots, 1920 x 1080 pixels, captured from the actual Avalonia UI
using the headless Skia renderer. No product code or icons were changed for
the capture.

Synthetic demo: 72 placeholder files in 12 subfolders under `C:\DiskStats-Demo`
(approximately 4.1 GiB). Files are scan fixtures, not playable media. Personal
drive labels and other drives are excluded from the capture sidebar. C: capacity
figures come from the capture machine.

Recommended upload order and English captions:

| Image | Caption |
| --- | --- |
| 01-Treemap | See disk usage at a glance with the treemap. |
| 02-Files | Compare files and subfolders by size. |
| 03-Sunburst | Explore folder hierarchies with the sunburst view. |
| 04-TopSizes | Find the largest files, with dark mode support. |

Use `de-*` for the German listing and `en-*` for the English listing. Translate
the suggested captions for the German listing. These screenshots were prepared
locally; they were not uploaded as part of the capture task.
